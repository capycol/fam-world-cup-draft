Scoring key & how to update

EventPoints
Win+3
Draw+1
Loss+0
Clean Sheet+1
Goal+1
Red Card-1

Adding a result

Open worldcup_dashboard.py and find the MATCHES list. For a match that has been played, add a dict with home_goals and away_goals:

{"date":"2026-06-19","home":"Brazil","away":"Argentina","home_goals":2,"away_goals":1},

If a team received red cards, add home_red_cards or away_red_cards:

{"date":"2026-06-19","home":"England","away":"France","home_goals":1,"away_goals":1,"home_red_cards":1},

Adding an upcoming match

Just omit the goals — the page will show it under Fixtures:

{"date":"2026-06-22","home":"Spain","away":"Germany"},

You can also add an optional "time":"20:00 UTC" field.

Regenerating the page

Run python worldcup_dashboard.py — it overwrites index.html. Commit and push to GitHub Pages and the link updates instantly.
